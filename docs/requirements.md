# 需求基线：按教师评教（第二版）

来源：2026-11-25 需求会议（转写稿在本地 `.codex/handoffs/S1-teacher-eval/`，不提交），以及会后用户的确认。
旧版按“学校 + 班级 + 学科”记录评分，本版改为按“班级 + 学科 + 任课教师”记录。

## 角色与可见范围

| 角色 | 能做什么 | 不能做什么 |
| --- | --- | --- |
| 学生 | 免登录，选学校、年级、班级后，给本班各科任课教师打分 | 不能看到任何结果 |
| 教师 | 实名登记本人信息，登记自己在本校任教的班级和学科 | 不能看到任何评价结果 |
| 校长 | 看本校看板，下钻到年级、学科、教师、班级；管理本校教师名单和任课关系 | 看不到其他学校的数据 |
| 平台管理员 | 管理学校、调研期、题目和账号，导入教师名单，看各校整体数据 | 看不到单个教师的得分 |

## 决策（2026-11-25）

- 教师有两种建档途径：管理员或学校用 Excel 批量导入，或教师自助注册。两种途径进同一张教师表。
- 教师身份以“学校 + 姓名 + 手机号”确定，手机号全局唯一。登录用姓名 + 完整手机号，不发短信验证码；连续输错要限制。
- 每个“班级 + 学科”只能有一位任课教师。已经有人登记的班级学科，其他人不能再登记，需要联系学校处理。暂不支持两位老师合上一门课。
- 学生只给已经登记了任课教师的学科打分。没有登记教师的学科不出现在问卷里。
- 答案保存提交时的任课教师。之后任课关系再调整，已经提交的评分不会改归属。
- 题目沿用量表形式，分值由选项决定，题目跨学科共用。
- 历史答卷不做兼容。上线前整库备份并归档，新版不展示历史数据。
- 学生匿名，任何角色都看不到单份答卷。
- 得分折算成百分制：平均分 ÷ 该题满分 × 100。
- 删除校长端的校际对比，校长只看本校。
- 部署环境未定，先在本地做完、验收。
